# 🍔 Projeto Lanchonete SENAC

Sistema de gerenciamento de uma lanchonete desenvolvido em **C#** como projeto acadêmico do curso Técnico em Desenvolvimento de Software do SENAC.

## 📌 Sobre o projeto

O objetivo é desenvolver um sistema de console para organizar as operações de uma lanchonete, permitindo acessar o cardápio, registrar vendas e consultar informações sobre produtos e faturamento.

## ⚙️ Funcionalidades

- [x] Menu principal interativo
- [x] Navegação por menus com `switch-case`
- [x] Repetição do menu com `do-while`
- [ ] Visualização do cardápio
- [ ] Validação de códigos de produtos
- [ ] Registro e consulta de vendas
- [ ] Cálculo de faturamento
- [ ] Relatórios de produtos e movimentação

> As funcionalidades serão marcadas como concluídas conforme forem implementadas e testadas pela equipe.

## 🛠️ Tecnologias utilizadas

- **Linguagem:** C#
- **Plataforma:** .NET
- **Ferramentas:** Visual Studio / Visual Studio Code
- **Versionamento:** Git e GitHub

## ▶️ Como executar

1. Clone este repositório:

   ```bash
   git clone https://github.com/AllxHen/projeto-lanchonete.git
   ```

2. Abra a pasta do projeto no Visual Studio ou Visual Studio Code.

3. Execute o projeto pelo terminal, caso ele esteja configurado como um projeto .NET:

   ```bash
   dotnet run
   ```
